# Sörkila Homebrew tap

Homebrew casks for [Sörkila](https://sorkila.com)'s native macOS apps.

## Tintpad

A menu-bar launcher that summons a coding agent (Claude Code, Codex, …) into your
terminal at the right repo. Free, open source, local-only. <https://tintpad.com>

```sh
brew install --cask sorkila/tap/tintpad
```
